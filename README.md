# Page web sur Zinedine Zidane



## Description



Ce site retrace le parcours de Zinedine Zidane.
Dans la page d'acceuil, il est décrit sa jeunesse et sa carrière.
Dans la seconde, en cliquant sur la section "les cartes", il présente quelques informations courtes sur Zinedine Zidane.



## Fonctionnalités



- Barre de navigation

- 2 pages interconnectées

- menu burger pour petits écrans

- Moyens de contact cliquables



## Technologies utilisées



- Html5

- CSS3



## Structure du projet



- index.html

- cartes.html

- style.css



## Installation



Cliquez sur index.html. Le navigateur va ouvrir la page d'accueil.

Les pages sont connectées ensemble via le menu dans la barre de navigation.
